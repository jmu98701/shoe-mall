# 鞋履精选小程序

基于 **uni-app + Vue 3** 的微信小程序商城前端原型，采用移动端简洁商品卡片与暖色系视觉设计。

## 当前包含

- 首页：新品横幅、商品列表、快捷加购
- 分类页：商品浏览与类别筛选视觉
- 商品详情：商品介绍、尺码选择、加入购物车
- 购物车：本地购物车数据、数量增减、金额合计
- 个人中心：订单入口及服务菜单占位
- 微信小程序与 H5 的构建脚本

## 本地运行

```bash
npm install
npm run dev:mp-weixin
```

然后用微信开发者工具打开 `unpackage/dist/dev/mp-weixin`。构建上传版本：

```bash
npm run build:mp-weixin
```

在 `manifest.json` 中填写你的小程序 AppID。需要 Node.js 18 或更高版本。若 DCloud 依赖版本不可用，请使用 HBuilderX 创建同版本 uni-app 项目或将 `@dcloudio/*` 依赖统一升级到当前兼容版本。
